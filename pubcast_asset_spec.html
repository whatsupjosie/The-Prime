Format standards, polygon budgets, and scene limits for all asset classes

PubWorld / Studio Engine

This document defines the technical standards for every asset class used in PubCast AI — avatars, props, sets, voxel objects, effects, and UI. These are not suggestions. They are the line between a scene that works and one that doesn't.

The core test for any asset class: can you comfortably place the expected count of them in a working studio scene alongside everything else? If you hesitate, it's too expensive. Build to leave room.

Every asset class draws from these pools. A scene with 6 avatars at 30k tris each has already spent 180k of the 400k working budget before a single prop or set piece is loaded.
File Formats
Format Hierarchy
GLB
First and default choice. Portable, browser-native, self-contained — geometry, materials, textures, skeleton, and animations in one file. Least likely to arrive broken. Required format for all browser-facing handoffs.
OBJ
Acceptable for raw geometry only. Materials and textures live in a separate MTL file — easy to lose in transit. No skeleton, no animation. Use as source format only, convert to GLB before shipping.
FBX
Useful as a pipeline source format, especially from Blender or Maya. Carries rigging and animation data well. Not for browser-facing handoff — convert to GLB. Binary FBX preferred over ASCII.
STL
3D print format only. No UV, no rig, no material. Do not ship STL for any PubCast asset without a full conversion pipeline. Treat it as raw geometry requiring UV unwrap, texture bake, and GLB export.
Asset Class 01
Avatars
Avatar Tiers
Characters that move, rig, and stack in scenes together
Tier Triangles Materials Textures Bones Expected Count
Default 15k – 30k 1 – 2 1k – 2k 89 3 – 6 per scene
Featured 30k – 60k 2 – 3 2k 89+ 1 – 2 per scene
Crowd 5k – 12k 1 512 – 1k 32 – 50 up to 12 per scene
Background 2k – 5k 1 512 none / impostor any
Skeleton standard: 89-bone UE5-compatible rig (Lumen / Azure / Nova presets). Bone names must follow UE5 PascalCase convention for retargeter compatibility.
Format: GLB with skeleton and idle animation baked in. FBX accepted as source; convert before shipping.
Transparent layered hair and clothing are expensive. Limit transparency stacking to 1 layer. Hard-surface hair mesh preferred over alpha card sheets.
If you hesitate before placing a third one, it's already too expensive for default tier.
Acceptable
Diffuse + normal map per character
Single atlas texture covering full body
Hard-surface hair mesh
Morph targets for facial expression
1 material per clothing layer
Do Not Ship
Over 60k triangles at any tier
More than 3 materials on one avatar
Layered alpha hair cards (3+ layers)
4k textures on default tier
Non-UE5 bone naming conventions
Asset Class 02
Props & Furniture
Prop Tiers
Objects that live in scenes alongside avatars and sets
Tier Triangles Materials Textures Use Case
Hero 2k – 8k 1 – 2 1k – 2k Close-up, story-critical, frequently seen
Standard 500 – 2k 1 512 – 1k Mid-ground, regularly placed
Background 100 – 500 1 256 – 512 Scene dressing, rarely close
A 40k triangle chair is inexcusable. Standard furniture should be Standard tier or below.
Hero props should be designated explicitly — not everything gets hero budget. Most props are Standard.
Destructible props: the voxel baker handles geometry. Triangle budget for baked voxel objects is governed by the Voxel Objects spec below.
Asset Class 03
Sets & Environments
Environment Tiers
Rooms, stages, and backgrounds. Biggest geometry budget, lowest movement cost.
Tier Triangles Materials Textures Notes
Full Room 20k – 50k 2 – 4 2k – 4k atlas Total budget for the entire room geometry
Modular Piece 500 – 2k 1 – 2 shared atlas Wall, floor, door, ceiling segment
Skybox / BG 1k – 5k 1 2k – 4k Static distant background only
Use texture atlases for sets. Multiple modular pieces sharing one atlas = one draw call. This is where draw call budget is won or lost.
Static sets have the largest triangle allowance because they are static. Do not waste that allowance on unseen interior faces — cull backfaces at export.
PubWorld voxel rooms are exempt from this spec — they are governed by the voxel system below.
Asset Class 04
Voxel Objects (Baked)
Voxel Bake Budgets
Authored in VoxelStudio, baked to GLB. Triangle count is determined by primitive count × shape complexity.
Class Max Tris (baked) Max Primitives Fragment Limit Example
Small detail < 2k 50 50 Candle, cup, small prop
Medium object 2k – 10k 200 200 Chair, table, crate
Large structure 10k – 30k 600 200 max Arch, column, wall section
Fragment limit at destruction: 200 per object regardless of primitive count. LOD of the authored object determines fragment detail — LOW breaks into big cubes, HIGH shatters into fine wedge and corner pieces.
Source voxel JSON must be kept alongside every baked GLB. The JSON is the editable source. The GLB is the artifact.
Large structures should declare pivot groups at authoring time if any section will carry a motion tracker or destruction hinge.
LOD levels: LOW / LOW-MED / MED / MED-HIGH / HIGH. These are authoring constraints, not render states. Different parts of the same object can use different LOD levels freely.
Asset Class 05
Effects & Particles
Effects Budget
No polygon budget. Draw call and particle count budget instead.
Type Max Particles Draw Calls Simultaneous
Ambient / idle 500 – 1k 1 3 per scene
Action / event 1k – 5k 1 – 3 2 per scene
Destruction debris up to fragment count 1 per object 2 simultaneous explosions
Destruction debris are voxel fragments — geometry, not particles. Fragment persistence is controlled by DestructionProfile.debris_persistence (default 8 seconds).
Avoid additive blending stacks. One additive layer over opaque is fine. Three additive layers on top of each other is a GPU problem.
Asset Class 06
UI Elements
UI Asset Rules
Almost free in geometry. Expensive if misused.
Prefer
HTML / CSS for all 2D UI
SVG for icons and decorative elements
CSS transitions over JS animation where possible
Under 500 tris for any 3D UI element
Single material per UI panel
Avoid
Transparency stack beyond 2 layers
Per-frame canvas redraws in the render loop
Live shader effects on scrolling text
3D UI elements over 500 tris
Unoptimised font rendering on large blocks
UI geometry budget is not shared with scene budget. UI lives in its own render pass. The cost is draw calls and overdraw, not triangles.
The Scene Test — Apply to Every Asset
Before approving any asset for production, place the expected number of them in a working studio scene alongside everything else that would normally be there — characters, set, props, UI, effects. If the scene hesitates, stutters, or you find yourself thinking twice before adding the third one, the asset is too expensive. Build to leave room. A beautiful asset that breaks the scene when multiplied is not a production-ready asset.
